# Book Tracker

A React application for logging books, tracking reading progress, setting annual reading goals, and viewing reading statistics.

## Features

- Add books with title, author, page count, and cover image
- Track reading progress (pages read vs total pages)
- Mark books as reading, completed, or want to read
- Set annual reading goals
- View reading statistics
- Search and filter your book list
- Local storage persistence

## Tech Stack

- React 19
- Vite
- React Router
- Tailwind CSS
- Vitest

## Getting Started

```bash
npm install
npm run dev
```
